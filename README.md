# Гардероб Кости

Персональный цифровой гардероб с каталогом вещей, конструктором образов и подготовкой запросов для реалистичной AI-примерки.

## Уже работает

- 25 вещей из гардероба
- фильтрация по категориям
- карточки вещей
- выбор верхнего слоя, основного верха и низа
- случайная сборка образа
- сохранение комплектов в браузере
- создание готового запроса для реалистичной примерки
- адаптивный интерфейс для iPhone

## Публикация
